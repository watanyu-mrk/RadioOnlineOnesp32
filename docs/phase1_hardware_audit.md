## 3. ตาราง GPIO ที่ยืนยันได้ (ตรงกัน ≥2 แหล่ง)

### 3.1 จอ ST7701 (RGB + SPI config)

| GPIO | ฟังก์ชัน | หมายเหตุ |
|------|----------|----------|
| 39 | LCD CS | SPI 9-bit |
| 48 | SPI SCK | ใช้ร่วมกับ SD |
| 47 | SPI MOSI | ใช้ร่วมกับ SD |
| 21 | PCLK | |
| 18 | DE | |
| 16 | HSYNC | — |
| 17 | VSYNC | |
| 38 | Backlight | LEDC PWM |
| 11,12,13,14,0 | R1–R5 | ลำดับจาก S3/S4 |
| 8,20,3,46,9,10 | G0–G5 | GPIO46 เป็น strapping |
| 4,5,6,7,15 | B1–B5 | |

**ข้อควรระวังจาก S4:** บางโครงการสลับ pin สีแดง/น้ำเงินและใช้ `0x3A 0x50`
ทำให้ได้ความละเอียดสีแดง/น้ำเงินเพียง 4 bit (สีเพี้ยน)
ลำดับที่ถูกต้องตาม S3 คือ red `11,12,13,14,0`, green `8,20,3,46,9,10`, blue `4,5,6,7,15`
และใน init sequence ต้องส่ง `0xFF 77 01 00 00 10` ตามด้วย `0xCD 0x00` (ปิด MDT flag)
ยังไม่ทดสอบกับบอร์ดจริงในโปรเจกต์นี้

### 3.2 ทัช GT911

| GPIO | ฟังก์ชัน |
|------|----------|
| 19 | I²C SDA |
| 45 | I²C SCL (strapping) |

INT ต่อลง GND และ RST ไม่ได้ต่อ GPIO (แหล่งข้อมูลระบุต่างกันเล็กน้อย) → **ห้ามจัดสรร GPIO สำหรับ INT/RST**
ตรวจสอบจริงด้วย I²C scan ที่ address 0x5D ใน Phase 2

### 3.3 microSD (SPI ร่วมกับจอ)

| GPIO | ฟังก์ชัน |
|------|----------|
| 42 | SD CS |
| 41 | SD MISO |
| 47 | SD MOSI (ร่วมจอ) |
| 48 | SD CLK (ร่วมจอ) |

### 3.4 รีเลย์ — ใช้ร่วมกับ I²S

| GPIO | รีเลย์ | I²S (NS4168) |
|------|--------|--------------|
| 40 | L1 | SDATA (DIN) |
| 2 | L2 | LRCK / LRCLK |
| 1 | L3 | BCLK |

### 3.5 พอร์ตที่เหลือ

| GPIO | สถานะ |
|------|--------|
| 43 / 44 | UART0 TX/RX ไป CH340 (header H1) — ใช้ได้ถ้าปิด serial log |
| 33–37 | **ห้ามใช้** (OPI PSRAM) |
| 26–32 | Flash/PSRAM — ห้ามใช้ |
| 41 / 42 | ว่างได้ถ้าไม่ใช้ SD (ต้องถอด pull-up ตาม S4) — ไม่แนะนำ |

**สรุป:** บอร์ดนี้แทบไม่มี GPIO ว่าง การเพิ่มอุปกรณ์ภายนอกต้องแลกกับ SD, UART หรือรีเลย์

## 4. วงจรเสียง — ข้อค้นพบสำคัญ

### 4.1 มีอะไรบนบอร์ด

- **NS4168** class-D mono amplifier + ขั้วลำโพง 1.25 mm (S4, S5)
- ลำโพงที่มากับชุด: UNISON U3608B35U 8 Ω 1.5 W (S4)
- ขา CTRL ของ NS4168 ถูก pull-up 1 MΩ ไป VCC → แอมป์เปิดตลอด (S4)
- I²S: BCLK = GPIO1, LRCLK = GPIO2, SDATA = GPIO40 (S4)

### 4.2 ข้อจำกัดที่ทำให้ยังใช้เสียงไม่ได้ทันที

GPIO1/2/40 ถูกต่อเข้าขับรีเลย์ L3/L2/L1 โดยค่าเริ่มต้น
คู่มือระบุว่าหากต้องการเสียง ต้องย้าย resistor 0 Ω **R25, R26, R27 → R21, R22, R23**
ซึ่งจะตัดรีเลย์ทั้งสามตัวออก (S4, S5, S6)

> นี่เป็นการแก้ฮาร์ดแวร์จริง (บัดกรี SMD) ตามกฎของโปรเจกต์จึง **ยังไม่ดำเนินการ**
> และต้องยืนยันกับบอร์ดของผู้ใช้ก่อน

### 4.3 ปัญหาเชิงสถาปัตยกรรม: ลำโพง mono vs Line Out

NS4168 เป็น **BTL mono speaker amplifier** ไม่ใช่ line output
ดังนั้น:

- ต่อลำโพง 8 Ω เข้ากับบอร์ด → ได้เสียง mono 1.5 W (ง่าย แต่ไม่ใช่ "เครื่องเสียงภายนอก" ตามโจทย์)
- ต่อเข้า AUX/RCA ของเครื่องเสียงภายนอกโดยตรง → **ห้าม** (เป็น speaker-level BTL ไม่ใช่ line-level
  และห้ามต่อฝั่งลบลงกราวด์)
- ถ้าต้องการ Line Out สเตอริโอจริง ต้องใช้ I²S DAC ภายนอก เช่น PCM5102A
  ต่อขนานกับสัญญาณ I²S เดียวกัน (BCLK/LRCLK/DIN) แล้วออกเป็น line level
  แต่ยังต้องเข้าถึง GPIO1/2/40 ซึ่งผ่านการย้าย resistor เช่นเดียวกัน

### 4.4 ทางเลือกที่ต้องให้ผู้ใช้ตัดสินใจ

| ทางเลือก | ต้องแก้ฮาร์ดแวร์ | ผลลัพธ์ | รีเลย์ |
|----------|------------------|---------|--------|
| A. ใช้ NS4168 + ลำโพงในตัว | ย้าย R25–R27 → R21–R23 | mono 1.5 W | ใช้ไม่ได้ |
| B. I²S DAC ภายนอก (PCM5102A) → AUX/RCA | ย้าย resistor + ต่อสาย I²S | stereo line out | ใช้ไม่ได้ |
| C. ไม่แก้บอร์ด | — | ไม่มีเสียง | ใช้ได้ |
| D. ใช้ SD/UART แทน | ดัดแปลงเพิ่ม | เสี่ยง/ไม่แนะนำ | ใช้ได้ |

## 5. สิ่งที่ยังไม่ยืนยัน (ต้องขอข้อมูลจากผู้ใช้)

1. **รุ่น/Revision ของบอร์ด** — SKU `_Y_1` (รีเลย์ 1 ตัว) หรือ `_Y_3` (3 ตัว) และมีแผงรีเลย์ต่ออยู่หรือไม่
2. **สถานะ resistor R25/R26/R27 vs R21/R22/R23** — ดูจากภาพ PCB ด้านหลัง/ใกล้ขั้วลำโพง
3. **มีขั้วลำโพงและ NS4168 อยู่จริงหรือไม่** — บอร์ดบางล็อตอาจไม่มีวงจรเสียง
4. **ตัวควบคุมทัช** — บางล็อตใช้ GT911, บางล็อตเป็น FT6336U ต้องยืนยันด้วย I²C scan
5. **เป้าหมายเสียง** — ลำโพง mono หรือ AUX/RCA สเตอริโอ
6. **จำเป็นต้องใช้รีเลย์หรือไม่** — เพราะใช้ GPIO ร่วมกับเสียง
7. **แหล่งจ่าย 5 V** — กระแสพอสำหรับแอมป์หรือไม่ (ยังไม่มีผลวัด)

## 6. แผน Phase 2 (Minimal Compile) — ยังไม่เริ่ม

1. สร้าง PlatformIO project (Arduino framework, `esp32-s3-devkitc-1`, 16 MB flash, OPI PSRAM)
2. ล็อกเวอร์ชัน Arduino_GFX / LVGL ที่คอมไพล์ผ่านจริง แล้วบันทึกผล
3. ทดสอบจอ + backlight + GT911 บนบอร์ดจริง
4. รายงาน heap ภายใน / PSRAM ว่าง / uptime ทาง Serial
5. **ไม่เขียนโค้ดเสียง** จนกว่าจะได้รับการยืนยันเป้าหมายเสียง (ข้อ 5) และสถานะ resistor (ข้อ 2) ในหัวข้อ 5
